STEM Foundations: Assessment-Driven Learning

Start with diagnostic assessment, then progress through personalized question banks building core STEM competencies.

  1. Diagnostic: Run stem-assessment-system quiz to identify knowledge gaps
  2. Foundations: Complete arithmetic, algebra, and scientific method modules
  3. Practice: Use stem-facilitator-toolkit lesson templates for guided exercises
